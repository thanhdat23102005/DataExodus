# DataExodus: my own DNS block list, added from what I measured on this network.
#
# The hand-picked list (pi/dns_trackers.txt) ships with the project. This file is
# the documented place for additions found in real use, and the DNS watch reloads
# it without a restart. A name here also blocks its subdomains, so a rotating
# subdomain cannot step around the entry.
#
# One domain per line. Give every entry a date and the evidence that justifies it:
# a DNS block is a decision about someone's network, so it should be defensible.
#
# Limits: blocking the name stops the advertiser's content loading, but it does
# not stop a tab from opening - the pop-under is opened by JavaScript inside the
# page the user is already on. Full prevention needs the Guard extension, which
# phone browsers cannot run, or Safe Browse on the Pi.
