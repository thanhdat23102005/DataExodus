# DataExodus DNS block list: advertising and analytics hosts, blocked by name.
#
# Used by the DNS watch (pi/dnswatch.py) in block mode and by "Block known
# trackers" on the DataExodus Wi-Fi, together with EasyPrivacy's whole-domain
# rules and URLhaus. EasyPrivacy blocks most big trackers by URL path, which a
# DNS server never sees, and Tracker Radar's categories are too coarse for DNS
# (it files google.com and cloudflare.com under tracking). This short list is
# hand-picked: hosts whose main job is ads, analytics or attribution, so that
# blocking them should not break the sites and apps that embed them. It is not
# exhaustive. A name here also blocks its subdomains. Add your own in
# data/blocklists/custom.txt, and exempt false positives with DNSWATCH_NEVER_BLOCK.
